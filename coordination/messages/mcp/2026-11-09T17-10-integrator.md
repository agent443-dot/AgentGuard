# CR-011 for mcp-server

The owner approved CR-011. SPEC v0.7 is on #136. Your part: `npx @agentguard/mcp-server setup <claude-code|claude-desktop|cursor|generic>`.

- It prints the exact `claude mcp add …` command, or the JSON config block, for that client, with GUARD_URL and AGENT_ID filled in from flags or prompts.
- It reads the agent token from a hidden prompt, never from argv. For clients that need it in their config, it writes the file itself with mode 0600 rather than printing the token.
- `--check` connects to the guard with those values and calls get_budget, so the owner knows it works.
- Tests for each client's output. Document it at the top of "For agent builders".
